FAQ:

What does it mean when it pops up with an error at the top?

The MusicBrains API is rate limited so you may have to wait a second before clicking on buttons or you may trigger the rate limit. If you get an error, just wait a second before proceeding.

Why are there multiple artists with the same name?

I don't really know, I think it's just a quirk with how anyone is able to create artists in MusicBrainz so duplicates turn up.

Some releases aren't showing up in the page?

This is a publicly updated API so it may not always be fully up to date
